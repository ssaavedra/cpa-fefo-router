Weekly outlook

Each provider's accounts as one pool: all demand is served from the account that resets soonest, lending spare quota. This is a best case — clients that never borrow can leave quota unused that this outlook spends.

Bucket lending limits

How much each bucket has lent this week against its limit. Set limits under Settings → Buckets.

Accounts

Each account's weekly and 5-hour quota windows, what its own clients are expected to use before the weekly reset, and the spare it can lend.

Clients

Where each client's next request would go, best first. A session stays on its account while that account keeps its place in the list.

Traffic since the plugin started

A client is one or more API keys (for example one machine or one project). Keys are CPA caller scopes (scripts/client-scope.sh) or plain sha256(key). Keys that belong to no client use the default client.
